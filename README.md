# Лендинг «Личная CRM»

Одна статичная страница: рассказывает о личной CRM и ведёт в приложение.
Сделана по макету из `design/` на Astro и Tailwind CSS 4.

## Как запустить у себя

Нужны Node.js 22+ и pnpm.

```sh
pnpm install
pnpm dev       # страница с автообновлением: http://localhost:4321
pnpm build     # готовая статика в папке dist/
pnpm preview   # посмотреть собранную версию из dist/
```

## Куда ведут кнопки

Все кнопки («Открыть», «Открыть приложение», «Добавить первый контакт») ведут на адрес
из переменной `PUBLIC_APP_URL`. По умолчанию это `https://app.stayintouch.site`
(задан в `astro.config.mjs`). Чтобы поменять адрес, добавьте строку в `.env`:

```
PUBLIC_APP_URL=https://app.example.com
```

## Где что лежит

- `src/styles/tokens.css` — дизайн-токены: цвета, шрифты, размеры текста, отступы, скругления
- `src/styles/global.css` — общие стили, маски фото, появление блоков при прокрутке
- `src/components/` — секции страницы: `Hero`, `Problem`, `Solution`, `Benefits`, `FinalCta`,
  а также шапка, футер, кнопка и карточка контакта
- `src/scripts/reveal.ts` — появление блоков и размытие фото при прокрутке
- `src/assets/` — фотографии; при сборке Astro сжимает их в AVIF/WebP
- `design/` — макет и исходные тексты (в сборку не попадает)
